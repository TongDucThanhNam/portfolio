### Definition of “Tailwind CSS v4 Only”

Allowed:

- `@import "tailwindcss" source("../");`
- `@theme` variables for color, typography, spacing, radii, shadows, easing, and animations.
- Keyframes tied to `--animate-*` theme variables.
- Tailwind utilities, arbitrary values, arbitrary properties, arbitrary variants, responsive
  variants, `motion-safe`, `motion-reduce`, `group`, `peer`, ARIA variants, and data variants.
- A very small `@custom-variant` or atomic `@utility` only when core/arbitrary utilities cannot
  express the requirement cleanly; each exception must be documented in `global.css`.
- Inline `style` only for genuinely runtime-derived values or CSS custom properties. Static values
  such as a fixed animation delay or initial transform belong in Tailwind classes.

Not allowed:

- Semantic component selectors such as `.portfolio-shell`, `.signal-*`, `.project-*`, `.tk-*`, etc.
- `@layer components`, `@apply`, CSS modules, Sass/Less/Stylus, styled-components, Emotion, or another
  styling runtime.
- Embedded `<style>` blocks.
- A Tailwind JavaScript config for values that v4 CSS-first `@theme` can express.
- Dynamically constructed Tailwind fragments such as `` `bg-${tone}-500` ``. Variant maps must
  contain complete literal utility strings so Tailwind can detect them.
- Static inline style objects used as a substitute for utilities.
- CSS/JS behavior coupled through styling class names. Use refs, `data-*`, or ARIA state as hooks.

### `check:tailwind-only` Audit Contract

Add a deterministic repository script, for example `scripts/check-tailwind-only.mjs`, and expose it
as `npm run check:tailwind-only`. It must fail when any of these conditions is true:

1. A source `.css` file exists outside `apps/web/src/styles/global.css`.
2. A source file contains an embedded `<style>` element, CSS module import, CSS-in-JS import,
   `@apply`, or `@layer components`.
3. `global.css` contains a semantic component selector or ordinary top-level selector outside
   Tailwind-owned directives/keyframes.
4. A retained TSX component dynamically assembles utility-name fragments that Tailwind cannot
   statically detect.
5. A static inline `style` value is used where a utility or arbitrary property can express it.
6. An inline style exception is not limited to a runtime value/CSS custom property and documented
   in a small allowlist.
7. A semantic class remains as both a behavior hook and styling dependency instead of using
   refs/data/ARIA state.
8. Legacy `nam-portfolio/style.css` or another standalone styling implementation remains.

The script must print a per-file failure list and return nonzero on failure. Do not implement it as
a hard-coded “always pass” marker or a line-count-only check.
